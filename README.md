# 🏛️ Archena Sports Hub - Flutter Mobile App 🚀

¡Bienvenido al repositorio oficial de la aplicación móvil de **Archena Sports Hub**! 

Esta aplicación ha sido diseñada con cariño para ofrecer a los ciudadanos de Archena la mejor experiencia a la hora de reservar sus pistas deportivas favoritas, todo desde la palma de su mano. 📱✨

---

## 🌟 Características Principales

*   **Identidad Institucional:** Interfaz premium con diseño *Glassmorphism* (desenfoques, transparencias y bordes suaves) y los colores oficiales del Ayuntamiento. 💙
*   **Descuento a Residentes:** ¡Un 20% de descuento automático en todas las reservas para ciudadanos empadronados! 📉
*   **Gestión Inteligente de Horarios:** El sistema bloquea de forma autónoma el solapamiento de reservas y calcula franjas estrictas de 60/90 minutos dependiendo de la pista. ⏱️
*   **Código QR de Acceso:** Confirmación instantánea de reservas con un código QR integrado para el acceso físico. 🎫
*   **Panel Administrativo:** Zona exclusiva para el Staff/Admin para gestionar y bloquear pistas por mantenimiento o lluvia. 🛠️

---

## 🛠️ Tecnologías Utilizadas

*   **Flutter & Dart** 🐦: Framework multiplataforma de Google para un rendimiento nativo.
*   **Supabase** ⚡: Backend as a Service (BaaS) para la base de datos PostgreSQL, autenticación y seguridad (RLS).
*   **Provider** 📦: Gestión de estado robusta, predecible y eficiente.

## 🚀 Cómo Empezar (Para Desarrolladores)

1.  **Clonar el proyecto:**
    ```bash
    git clone https://github.com/tu-usuario/flutter-archena-sports.git
    cd flutter-archena-sports
    ```

2.  **Instalar dependencias:**
    ```bash
    flutter pub get
    ```

3.  **Configurar Variables:**
    El proyecto ya está conectado al entorno de producción en `lib/main.dart`. ¡Asegúrate de no subir claves secretas a repositorios públicos! 🤫

4.  **Ejecutar la App:**
    Abre tu simulador (iOS/Android) o conecta tu dispositivo y lanza la magia:
    ```bash
    flutter run
    ```
